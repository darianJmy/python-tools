## 二、完整数据流图（含所有增强功能）

```
用户提问
  ↓
┌──────────────────────────────────────────────────────────────┐
│ 1. 上下文管理器（多轮对话）                                   │
│    ├─ 提取实体引用（Pod名称、数据库名等）                     │
│    ├─ 解析指代词（这、那、它 → 具体资源）                     │
│    ├─ 更新焦点资源（最近提到的资源）                          │
│    └─ 构建消息列表（系统提示 + 历史 + 当前）                  │
└──────────────┬───────────────────────────────────────────────┘
               ↓
┌──────────────────────────────────────────────────────────────┐
│ 2. 知识库搜索器（知识库）                                     │
│    ├─ 搜索相关知识（故障排查、最佳实践、FAQ）                 │
│    ├─ 返回 Top 3 最相关条目                                   │
│    └─ 注入到系统提示                                          │
└──────────────┬───────────────────────────────────────────────┘
               ↓
┌──────────────────────────────────────────────────────────────┐
│ 3. 大模型调用（eino 框架）                                    │
│    ├─ 输入：系统提示 + 上下文 + 当前问题                      │
│    ├─ 输出：回答 或 工具调用请求 或 任务计划                  │
│    └─ 记录 Token 使用                                         │
└──────────────┬───────────────────────────────────────────────┘
               ↓
        ┌──────┴──────┐
        │ 判断类型     │
        └──┬───┬───┬──┘
           │   │   │
      简单回答 单工具 多工具
           │   │   │
           ↓   ↓   ↓
        直接  单工具 任务规划器
        返回  执行    │
                ↓    │
             权限    │
             检查    │
                ↓    │
             缓存    │
             查询    │
                ↓    │
             工具    │
             执行    │
                ↓    │
             结果 ←──┘
             汇总
                ↓
┌──────────────────────────────────────────────────────────────┐
│ 4. 权限检查器（细粒度权限）                                   │
│    ├─ 检查用户角色（实习生/运维/管理员）                      │
│    ├─ 检查时间窗口（工作时间/非工作时间）                     │
│    ├─ 检查资源范围（web-* / db-* / *）                        │
│    └─ 返回：允许 / 拒绝 / 需要审批                            │
└──────────────┬───────────────────────────────────────────────┘
               ↓
        ┌──────┴──────┐
        │ 需要审批？   │
        └──┬───────┬──┘
           │       │
          是       否
           │       │
           ↓       └────→ 继续执行
    ┌────────────┐
    │ 审批流程   │
    │ ├─ 弹出对话框 │
    │ ├─ 用户确认   │
    │ └─ 记录日志   │
    └─────┬──────┘
          ↓
┌──────────────────────────────────────────────────────────────┐
│ 5. 缓存管理器（缓存复用）                                     │
│    ├─ 查询缓存（工具名 + 参数哈希）                           │
│    ├─ 缓存命中 → 直接返回                                     │
│    └─ 缓存未命中 → 继续执行                                   │
└──────────────┬───────────────────────────────────────────────┘
               ↓
┌──────────────────────────────────────────────────────────────┐
│ 6. 工具执行器（增强版）                                       │
│    ├─ 执行工具调用                                            │
│    ├─ 失败时自动重试（最多3次，指数退避）                     │
│    ├─ 记录执行详情（输入、输出、耗时、状态）                  │
│    └─ 只读操作写入缓存                                        │
└──────────────┬───────────────────────────────────────────────┘
               ↓
┌──────────────────────────────────────────────────────────────┐
│ 7. 追踪器（可观测性）                                         │
│    ├─ 记录每个步骤（上下文更新、LLM调用、工具调用）           │
│    ├─ 记录性能指标（总耗时、Token使用、工具调用次数）         │
│    └─ 记录错误信息（如果有失败）                              │
└──────────────┬───────────────────────────────────────────────┘
               ↓
┌──────────────────────────────────────────────────────────────┐
│ 8. 结果汇总                                                   │
│    ├─ 收集所有工具结果                                        │
│    ├─ 部分失败时降级处理                                      │
│    └─ 传递给大模型生成最终回答                                │
└──────────────┬───────────────────────────────────────────────┘
               ↓
┌──────────────────────────────────────────────────────────────┐
│ 9. 返回给用户                                                 │
│    ├─ 显示回答                                                │
│    ├─ 显示执行详情（可展开）                                  │
│    └─ 显示反馈按钮（有帮助/无帮助）                           │
└──────────────┬───────────────────────────────────────────────┘
               ↓
┌──────────────────────────────────────────────────────────────┐
│ 10. 用户反馈（可选）                                          │
│    ├─ 收集评分（1-5星）                                       │
│    ├─ 收集评论                                                │
│    └─ 用于持续优化                                            │
└──────────────────────────────────────────────────────────────┘
```

## 七、预期效果对比

```
┌─────────────────────────────────────────────────────────────────┐
│                    增强前 vs 增强后                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  对话能力                                                        │
│  ├─ 增强前：单轮对话，无法理解上下文                            │
│  └─ 增强后：多轮对话，支持追问和指代词解析                      │
│                                                                  │
│  工具调用                                                        │
```
